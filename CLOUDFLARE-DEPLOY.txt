MN Food Wins — Cloudflare deployment

Build command:
pnpm run build

Deploy command:
npx wrangler deploy

wrangler.jsonc sets the mncloud3v2 Worker entrypoint and its assets binding.
The Cloudflare Vite plugin generates .wrangler/deploy/config.json so the
existing deploy command selects the built server automatically.
Do not deploy dist/client alone: it contains assets, not the page/API server.
